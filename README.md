# Ashab VIP Portfolio v2

Premium dark/light glassmorphism Next.js portfolio.

## Run
npm install
npm run dev

Open http://localhost:3000

## Customize
Edit `data/site.ts` for portfolio content.
Put your profile image at `public/images/profile.jpg`.
Put the CV at `public/Ashab-Ahmed-Kasmani-CV.pdf`.

## Build
npm run build
npm run start
